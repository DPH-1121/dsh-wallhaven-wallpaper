# dsh-wallhaven-wallpaper

在 DeepSeek Harness 的设置里搜索 wallhaven.cc，点一下就把图片铺成 Web GUI 背景：图片由宿主进程取回（可单独配代理），背景通过重写主题表面 token 透出来，可下载原图、随时关掉恢复原样。

![设置页](docs/settings.png)

代理探测、分级与 API Key、网络边界等细节见[使用说明](./docs/guide.md)。

## 安装

见 [**DSH 插件安装教程**](https://github.com/DPH-1121/dsh-plugins/blob/main/docs/install.md)。

## 其他 DSH 插件
